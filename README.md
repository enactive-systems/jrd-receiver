# JR-D Receiver

JR-Dタイプ列車無線受信アプリ「JR-D Receiver」の、不具合の報告と要望の受付、リリースノートの置き場です。
アプリ本体のソースコードは、このリポジトリにはありません。

- 導入の案内とドキュメント: https://jrd.enactive-systems.com
- 不具合の報告と要望: [Issues](https://github.com/enactive-systems/jrd-receiver/issues/new/choose)
- 対応の状況と、次の版に入る予定の機能: [プロジェクト](https://github.com/orgs/enactive-systems/projects/2)
